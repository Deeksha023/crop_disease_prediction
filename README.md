# 🌱 Crop Disease Prediction

## 📌 Project Overview

Crop Disease Prediction is a machine learning project that predicts crop diseases using a given dataset.

The project demonstrates the basic steps of a machine learning workflow, including data loading, data preprocessing, visualization, model training, and model evaluation.

## 🎯 Objective

The main objective of this project is to use machine learning algorithms to predict crop disease based on the information provided in the dataset.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Machine Learning Algorithms

The following classification algorithms are used:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## 📊 Machine Learning Steps

1. Import required libraries
2. Load the dataset
3. Understand the dataset
4. Check missing values
5. Perform data preprocessing
6. Encode categorical data
7. Split the dataset into training and testing data
8. Train machine learning models
9. Make predictions
10. Evaluate the models

## 📈 Model Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix
- Classification Report
